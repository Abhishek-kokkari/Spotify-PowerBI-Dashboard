# Spotify-PowerBI-Dashboard
Interactive Spotify Analytics Dashboard built with Microsoft Power BI using DAX, Power Query, data modeling, and interactive visualizations.

# 🎵 Spotify Power BI Dashboard

## 📌 1. Project Title

**Spotify Power BI Dashboard – Interactive Music Analytics Dashboard**

---

# 📖 2. Project Description

The **Spotify Power BI Dashboard** is an interactive Business Intelligence project developed using **Microsoft Power BI** to analyze Spotify music streaming data. The dashboard transforms raw music data into meaningful insights through dynamic visualizations, KPI cards, and interactive filters.

This project demonstrates the complete Power BI workflow, including **data cleaning, transformation, data modeling, DAX calculations, and dashboard design**. It enables users to explore artist performance, track popularity, album distribution, release trends, and overall music insights through an intuitive reporting interface.

The objective of this project is to showcase how Business Intelligence tools can convert large datasets into actionable insights for better decision-making and data storytelling.

---

# 🎯 3. Project Objectives

The primary objectives of this dashboard are:

- Analyze Spotify music data using Power BI.
- Monitor song popularity and artist performance.
- Identify top-performing tracks and albums.
- Visualize music trends over time.
- Build an interactive dashboard using professional BI practices.
- Demonstrate practical Power BI, DAX, and Power Query skills.

# 📂 5. Data Source

**Dataset:** Spotify Songs Dataset

The dataset contains information about Spotify tracks, including:

- Song Name
- Artist Name
- Album Name
- Album Type
- Release Date
- Popularity Score
- Track Information
- Audio & Music Metadata

The data was imported into Power BI, transformed using Power Query, and modeled to support interactive reporting.

# ✨ 6. Dashboard Features

- Analyze Spotify songs and artists.
- Compare track popularity across artists.
- Explore album distribution and releases.

- Dynamic slicers and filters.
- Cross-filtering between visuals.
- Interactive navigation across pages.

Display important metrics such as:

- Total Songs

- Most popular artists.
- Song contribution by artist.

- Release trends.

### 📅 Time Analysis

- Songs released by Year.

- Highest Popularity Songs.
